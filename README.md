# SnapScape

SnapScape is an image-discovery website where users will be able to search for images by topic. The website uses a forest-green and cream colour palette to create a calm, nature-inspired appearance. I added category suggestion chips to make common searches easy to discover. I also included an empty-state message so users understand what to do before any results appear.
